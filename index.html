1看懂报告

拿到病理、影像、化验报告先别慌，按下面顺序看：是什么病、到哪一期、指标代表什么。

病理报告怎么看（最重要的一张纸）

病理报告是诊断的「金标准」，也是决定治疗方案的核心依据。重点看这几项：

  • 组织学类型：是哪一种癌（如胰腺导管腺癌、胆管腺癌、甲状腺乳头状癌等）。不同类型的治疗和预后差别很大。
  • 分化程度：高/中/低分化。分化越低通常恶性度越高，但要结合其他指标一起看。
  • 切缘：报告写「切缘阴性 / R0」表示手术切干净了；写「阳性 / R1」说明可能没切净，医生会考虑补充治疗。
  • 淋巴结：清扫了多少个、几个有转移。淋巴结转移情况直接影响分期和后续治疗。
  • 脉管癌栓 / 神经侵犯：出现提示复发风险略高，医生会据此加强随访。
  • 免疫组化（IHC）：一堆字母（如 CK7、CK19、Ki-67、降钙素…），用于确认来源和分型，家属不用逐项深究。
两个实用动作：① 看不懂的地方列成问题清单，问医生时逐条问；② 如果对诊断有疑问或想确认，可以申请病理会诊（带上蜡块/切片到上级医院复核），很多大医院有会诊流程。
肝癌的病理类型与关键指标
  • 肝细胞癌（HCC）：最常见，占原发性肝癌 80-90%。与乙肝/丙肝、肝硬化、酒精肝密切相关。
  • 肝内胆管癌（ICC）：次常见，治疗思路接近胆管癌，建议做基因检测（FGFR2、IDH1）。
  • 混合型：少见，兼有两种成分。
  • 重点看：肿瘤大小和个数、血管侵犯（门静脉/肝静脉癌栓是预后差的重要因素）、分化程度、切缘。
肝癌的诊断常不依赖病理穿刺——影像典型+AFP升高即可临床诊断。穿刺主要用于不典型病例。
胰腺癌的病理类型速览
  • 胰腺导管腺癌（PDAC）：最常见、恶性度高，多数确诊偏晚。治疗以化疗为主，基因检测（BRCA、KRAS G12C、MSI 等）可帮找机会。
  • 胰腺神经内分泌肿瘤（NET）：占少数，比导管腺癌「温和」很多，生长慢，治疗和随访策略完全不同。
  • 囊性肿瘤（如 IPMN）：部分有癌变风险，需要按医生要求定期随访。
胆管癌与胆囊癌的病理类型速览
  • 绝大多数是腺癌。胆囊癌常与长期胆囊结石、慢性胆囊炎有关（但绝大多数结石患者不会得胆囊癌，不用过度恐慌）。
  • 胆管癌分肝内、肝外，两者治疗策略有差异；肝内胆管癌建议做基因检测（FGFR2、IDH1 等有对应药物）。
  • 胆管癌的免疫组化常查 HER2，阳性者有对应靶向治疗机会。
十二指肠癌的病理类型速览
  • 多为腺癌，治疗思路接近小肠/结直肠癌。
  • MSI-H（微卫星不稳定高）比例相对高，意味着免疫治疗机会大——建议检测 MSI/MMR 状态。
  • 少数为神经内分泌肿瘤、间质瘤等，治疗完全不同。
甲状腺癌的病理类型速览
  • 乳头状癌：最常见（约占 85-90%），生长慢、预后最好，很多「带瘤生存」很多年。
  • 滤泡状癌：次常见，总体预后也好。
  • 髓样癌：少见，与 RET 基因相关，需要查降钙素，治疗思路不同。
  • 未分化癌：极罕见但恶性度极高，需多学科团队处理。
甲状腺癌里约 95% 是预后良好的分化型（乳头状+滤泡状），「一得甲状腺癌就完了」是最大的误解。
TNM 分期是什么、决定什么
  • T＝原发肿瘤：大小、侵犯深度（如胰腺癌是否侵犯血管，甲状腺癌是否突破包膜）。
  • N＝淋巴结：有没有转移、转移区域。
  • M＝远处转移：有没有转移到肝、肺、骨等。
  • 组合成 Ⅰ-Ⅳ 期，决定治疗路线：早期以手术为主，晚期以全身治疗为主。
提醒：① 「临床分期」和「术后病理分期」可能不同，最终以病理分期为准；② 不同癌种的分期标准不一样，不要拿别人的报告套自己的；③ 分期不等于判死刑——同一分期里个体差异很大，治疗手段也在不断进步。
肝癌标志物：AFP 怎么看
  • AFP（甲胎蛋白）：肝癌最常用的标志物。但部分肝病（肝炎、肝硬化）也会偏高，需结合影像。
  • AFP 持续大幅升高 → 警惕肝癌活动；治疗后下降 → 提示治疗有效。
  • 约 30% 肝癌患者 AFP 不升高，「正常 ≠ 没事」，要结合影像（增强 CT/MRI）。
标志物只看「同一家医院同一项指标」的纵向趋势，单次数值意义有限。
胰腺/胆道/十二指肠标志物：CA19-9 与 CEA
  • CA19-9：胰腺癌、胆管癌、胆囊癌最常用，但胆管炎、黄疸、胰腺炎都会让它升高——单独一次升高不等于复发，要看连续趋势。
  • CEA：消化道肿瘤通用参考，十二指肠癌也会看。
  • 约 20-30% 的患者不分泌标志物，「正常 ≠ 无复发」。
三个原则：① 标志物「升高 ≠ 复发」，必须结合影像和医生判断；② 「正常 ≠ 无复发」；③ 只用「同一家医院的同一项指标」纵向比较才可靠。
甲状腺标志物：甲功 / Tg / 降钙素
  • TSH / T3 / T4：看甲状腺功能，术后吃优甲乐后需定期监测调整。
  • Tg（甲状腺球蛋白）：分化型甲状腺癌术后随访核心指标。Tg 持续下降或测不到 = 好信号；Tg 升高需排查残留/复发。注意：Tg 抗体阳性时 Tg 会受干扰，需同时查 TgAb。
  • 降钙素：髓样癌专属指标，用于诊断和随访监测。
影像报告高频词（CT / MRI / PET-CT / 超声）
  • 增强 CT/MRI：看「动脉期、门脉期、延迟期」的强化方式，判断病灶血供与性质；「边界清晰/模糊、有无坏死、有无血管侵犯」是关键。
  • PET-CT：看代谢活性（SUVmax）。炎症也会「假阳性」，不是 SUV 高就一定是癌。
  • MRCP：无创看胆道全程，是胆管结石、胆管梗阻的重要检查。
  • 超声：肝胆胰和甲状腺的一线检查；甲状腺报告重点看分级（下一节专讲）。
实用建议：随访时尽量带原片（光盘或二维码）而不是只带报告单，不同医院医生可以自己阅片对比。
甲状腺结节报告专讲（TI-RADS / C-TIRADS / 穿刺报告）

先说结论：甲状腺结节非常常见（成人超声检出率可达 20-70%），其中 90% 以上是良性；即便恶性，绝大多数也是预后很好的甲状腺癌。

超声分级怎么读

  • 国内报告常见 TI-RADS（1-5 类）或 C-TIRADS（1-6 类），数字越高，恶性风险越高。
  • 一般：3 类及以下恶性风险很低，定期复查即可；4 类及以上需要专科评估，医生可能建议穿刺（FNA）或手术；5/6 类高度怀疑或已确诊恶性。
  • 报告里「低回声、边界不清、纵横比＞1、微钙化、淋巴结异常」等描述会增加风险评分——但由医生综合判读，家属不要自己逐条对照吓自己。

穿刺（FNA）报告 Bethesda 分级怎么读

  • Ⅰ 类：取材不满意，可能要重穿。
  • Ⅱ 类：良性，随访即可。
  • Ⅲ / Ⅳ 类：意义不明确/滤泡性病变——不能确定，医生会根据结节大小和超声特征决定：再穿、观察或手术。
  • Ⅴ 类：可疑恶性；Ⅵ 类：恶性——通常建议手术。
分级是「风险评估」不是「确诊」，最终诊断以手术后的完整病理为准。良性结节一般 6-12 个月复查一次超声，连续稳定可延长间隔。

2治疗怎么选

先看「能不能手术」，再看「要不要化疗/靶向/免疫」，最后看「局部治疗有没有机会」。

肝癌治疗路径
  • 早期：手术切除 / 消融 / 肝移植，肝功能是核心决定因素。
  • 中期：介入治疗（TACE / HAIC）。
  • 晚期：系统治疗为主——靶向（索拉非尼、仑伐替尼等）+ 免疫（阿替利珠单抗+贝伐珠单抗、信迪利单抗+贝伐珠单抗等）。
肝癌的治疗方案高度依赖肝功能（Child-Pugh 分级），同样的肿瘤在不同肝功能背景下选择可能完全不同。
胰腺癌治疗路径
  • 可切除：先手术，术后辅助化疗。
  • 交界可切除：先化疗（新辅助）降期，再评估手术。
  • 不可切除：系统化疗为主（FOLFIRINOX 或吉西他滨+白蛋白紫杉醇），放疗用于局部控制；基因检测找靶向/免疫机会。
胰腺癌的关键问题是「能不能切」——建议在大医院（胰腺中心）评估可切除性，不要轻易放弃。
胆管癌与胆囊癌治疗路径
  • 可切除：手术是首选；术后按情况辅助治疗。
  • 不可切除：一线吉西他滨+顺铂+免疫（度伐利尤单抗或帕博利珠单抗）；二线按基因结果选药：
    • FGFR2 融合 → 佩米替尼
    • IDH1 突变 → 艾伏尼布
    • HER2 阳性 → 抗 HER2 治疗
胆管癌一定要做基因检测——FGFR2、IDH1、HER2、BRAF 等都可能找到精准治疗机会。没有基因检测结果等于放弃了一整类治疗选择。
十二指肠癌治疗路径
  • 可切除：胰十二指肠切除术（Whipple），术后按小肠癌方案辅助化疗。
  • 晚期：FOLFOX / FOLFIRI 类方案 + 按基因结果加靶向/免疫。
Whipple 手术是大手术，建议在经验丰富的中心进行。术后恢复期较长，家属要有心理准备。
甲状腺癌治疗路径
  • 分化型：手术（腺叶或全切）→ 高危者碘131 → 终身优甲乐（见下节）。低危微小癌（≤1cm、无高危特征）可以选择「积极监测」不立即手术，国内外指南都认可。
  • 髓样癌：全切+淋巴结清扫，查降钙素、做 RET 基因检测。
  • 未分化癌：罕见，需多学科团队和临床试验机会。
胆囊结石怎么治
  • 有症状（胆绞痛）→ 腹腔镜胆囊切除，是成熟小手术，创伤小、恢复快。
  • 无症状小结石 → 观察随访；但结石大（≥3cm）、胆囊壁增厚/瓷化、合并息肉等，医生可能建议切除（防远期癌变）。
  • 急性胆囊炎 → 急诊抗感染+限期手术。
「切了胆囊会不会影响消化」是家属最常问的：大部分人术后适应良好，早期少吃油腻即可，不影响寿命和生活质量。
胆总管结石怎么治
  • 主要靠 ERCP 取石（经口内镜，可同时切开胆管口 EST）或腹腔镜手术取石。
  • 很多患者胆囊结石和胆总管结石同时存在，可能需要 ERCP 取石 + 腹腔镜胆囊切除「两步走」。
  • 急性胆管炎（腹痛+寒战高热+黄疸）是急症，需要急诊 ERCP，千万不要拖。
ERCP 取石后仍有复发可能，按医生要求复查（超声/MRCP），出现症状别拖。
治疗手段都是什么（手术 / 介入 / 消融 / 放疗 / 化疗 / 靶向 / 免疫 / 碘131）
  • 手术：根治机会最大的手段，但不是所有分期都适合。
  • TACE / HAIC（介入）：把药打到肝脏肿瘤供血动脉里，肝癌常用，创伤小。
  • 消融（射频/微波）：用热能「烧掉」小病灶，适合早期小肝癌等。
  • 放疗：用射线杀肿瘤，局部控制用；胰腺癌、胆管癌常用作辅助。
  • 化疗：全身用药，胰腺癌、胆道癌的一线主力。
  • 靶向治疗：精准打击特定基因靶点（需基因检测结果匹配）。
  • 免疫治疗（PD-1/PD-L1 抑制剂）：调动自身免疫系统杀肿瘤，常与化疗/靶向联用。
  • 碘131：甲状腺癌专属，术后清除残留甲状腺组织和转移灶，需要先低碘饮食准备。
同一个癌种、不同患者方案可能完全不同。家属要问清楚三件事：为什么选这个方案、目的是什么（根治/控制/延长）、副作用是什么。
化疗 / 靶向 / 免疫治疗的副作用居家管理

化疗常见副作用

  • 恶心呕吐：止吐药按时吃（预防比治疗有效），少食多餐、清淡。
  • 骨髓抑制：白细胞/血小板下降。化疗后发热（尤其 38℃ 以上）是急症，立即查血，不要在家硬扛。
  • 腹泻：补水和电解质，严重时就医。
  • 手足综合征 / 口腔黏膜炎：保湿、软食、按医嘱用药。

靶向药常见副作用

  • 高血压：每天量血压，按医嘱处理。
  • 皮疹 / 手足皮肤反应（索拉非尼、仑伐替尼等常见）：保湿防晒，别抓破。
  • 蛋白尿、出血倾向：定期复查，注意牙龈出血、皮下瘀斑。

免疫治疗常见副作用（要学会识别，因为「像小毛病但可能是大事」）

  • 皮疹/瘙痒、甲状腺功能异常（定期查甲功）。
  • 免疫性肺炎：干咳、气短 → 及时就医。
  • 免疫性肝炎：乏力、转氨酶升高 → 复查肝功能。
  • 免疫性结肠炎：持续腹泻、便血 → 就医。
  • 心肌炎：胸痛、心慌 → 立即急诊。
总原则：绝大多数副作用可以管理，但不要因为副作用自行停药、减药；出现上面任何「严重信号」先联系医生或去急诊，带上正在吃的所有药清单。
甲状腺癌治疗专讲（优甲乐 / 碘131 / 术后注意事项）

优甲乐（左甲状腺素）——甲状腺术后的「终身朋友」

  • 作用：① 补充甲状腺素；② 把 TSH 抑制在目标范围，减少复发风险。
  • 每天早晨空腹服用，与早餐至少间隔 30-60 分钟；与钙片、铁剂、胃药间隔 4 小时以上。
  • 剂量由 TSH 决定，需定期复查甲功调整；不要自行停药或加量。

碘131 治疗

  • 用于中高危分化型甲状腺癌术后「清甲/清灶」；不是所有患者都需要，听医生判断。
  • 治疗前 1-2 周低碘饮食：不吃海带、紫菜、海鱼海虾、含碘调味品，用无碘盐。
  • 治疗后按医嘱短期隔离（避免与孕妇、婴幼儿密切接触），多喝水、可含酸糖保护唾液腺。

全切术后要警惕的两件事

  • 低钙：术后甲状旁腺功能受影响，出现手麻、口唇麻木、肌肉抽搐 → 及时就医，按医嘱补钙和维生素D。
  • 颈部出血：术后 24 小时内颈部迅速肿胀、憋气、呼吸困难 → 立即呼叫医护/急诊，这是急症。
声音嘶哑可能与喉返神经受牵拉有关，多数会慢慢恢复；持续不缓解需复查。
临床试验怎么找、怎么入组
  • 官方查询：国家药监局「药物临床试验登记与信息公示平台」（chinadrugtrials.org.cn），可按癌种检索。
  • 更直接的方式：问你的主治医生所在科室有没有在招募的试验，或去大医院官网/公众号查「临床研究招募」。
  • 正规试验：药物和相关检查免费，还有知情同意书和伦理保障。任何以「入组费、押金」为名的都是骗局。
  • 入组需要符合「入选标准」，不符合也别失落——医生会给出常规治疗建议。

3居家护理与营养

治疗之外，家属能做的最多——吃、睡、疼、症状观察，这一块全讲清楚。

营养支持（肝胆胰患者尤其重要）
  • 胰腺/胆道术后：常需胰酶替代（随餐服用，把药混在饭里一起消化），少食多餐、高蛋白高能量。
  • 胆道梗阻/黄疸期：脂肪吸收差，饮食宜低脂；可用中链甘油三酯（MCT）油/奶粉补能量。
  • 吃不下、明显消瘦：请营养科会诊，用口服营养补充剂（ONS），必要时肠内/肠外营养——营养支持本身就是治疗的一部分。
最常见的营养误区：「饿死癌细胞」是错的——肿瘤患者营养不良会更快垮掉；「大补」乱吃人参灵芝等，可能与抗凝药、靶向药相互作用，进补前先问医生或营养师。
胆囊结石患者的饮食与生活
  • 低脂清淡：少吃油炸、肥肉、动物内脏、奶油等高脂食物。
  • 规律三餐：尤其要吃早餐——空腹时间过长使胆汁淤积，容易形成新结石。
  • 控制体重：肥胖是胆结石风险因素，但减肥也不宜过快。
  • 忌暴饮暴食：尤其节假日，大量高脂饮食是诱发急性胆囊炎的常见原因。
胆囊切除术后 1-2 个月低脂饮食，之后可逐步恢复正常饮食，大部分人没有长期饮食限制。
胆总管结石 / ERCP 术后注意事项
  • 未手术的胆总管结石：低脂规律饮食，避免暴饮暴食；胆绞痛发作（右上腹剧痛、可放射到右肩背）时先禁食、就医。
  • ERCP 取石术后：按医嘱短暂禁食后逐步恢复饮食；观察有无腹痛、发热、黄疸——这些可能是胆管炎或胰腺炎再发的信号。
  • 急性胆管炎信号（务必记住）：腹痛 + 寒战高热 + 黄疸（Charcot 三联征），是危及生命的急症，立即急诊。
  • 胆总管结石取石后仍有复发可能，按医生要求复查（超声/MRCP），出现症状别拖。
甲状腺术后居家护理
  • 切口：保持干燥清洁，按医嘱换药拆线；睡觉可垫高枕头。
  • 声音：嘶哑多数可恢复，少说话、别大喊；持续不缓解复查声带。
  • 低钙：手麻、口唇麻、抽搐 → 及时就医，按医嘱补钙。
  • 优甲乐规律服药（见「甲状腺癌治疗专讲」）；定期复查甲功和 Tg、超声。
  • 碘131 前后按医嘱低碘饮食和隔离。
黄疸 / 腹水 / 癌痛的家庭护理

黄疸

  • 皮肤瘙痒：保持皮肤湿润、涂温和润肤霜，抓破易感染。
  • 观察大小便颜色（陶土样便/浓茶样尿提示梗阻加重）；胆管支架/引流术后注意引流管护理和固定。

腹水

  • 按医嘱限盐、必要时限水；每天固定时间称体重、量腹围记录。
  • 利尿药按时吃；腹围短期明显增大伴呼吸困难 → 就医，可能需要放腹水。

癌痛（家属最心疼、最无能为力的部分）

  • 三阶梯止痛：按时、按量服药，不要「忍」，不要等疼了才吃——规律给药才能把痛压在萌芽里。
  • 「吃止痛药会上瘾」是最大误区：癌痛规范用药成瘾率极低，疼痛控制比「怕上瘾」重要得多。
  • 吗啡类常见便秘：预防性处理（多喝水、按医嘱用缓泻剂）；恶心多在初期，之后会缓解。
  • 疼痛控制不好：主动找医生调方案，肿瘤科有专门的疼痛门诊。
家属怎么沟通、怎么陪（心理支持）
  • 告知策略：尊重患者意愿——多数专家建议逐步、坦诚告知，患者有权利参与决策；「全瞒着」往往造成更大的猜疑和情绪反弹。
  • 让患者保留选择权：治疗决策尽量让本人参与（分期、风险讲清楚后由本人定），这能显著减少「被安排感」和焦虑。
  • 陪伴技巧：多倾听、少建议；不说「你要坚强」这种压力话，说「我在，我们一起想办法」。
  • 家属也要照顾自己：允许自己崩溃和休息，找病友群或心理科支持；你垮了，患者更没依靠。
  • 记录症状和问题清单，每次复查前写好，见医生时逐条问（见第 6 部分模板）。

4急诊警示清单

这一节值得截图保存。出现下列任何情况，立即联系医生或去急诊，不要先在网上搜答案。

立即

呕血、黑便（柏油样便）——消化道出血。

立即

剧烈腹痛、腹痛持续不缓解——警惕急性胆囊炎、胆管炎、胰腺炎。

立即

腹痛 + 寒战高热 + 黄疸——急性胆管炎，可危及生命。

立即

化疗/免疫治疗后发热 ≥38℃——可能粒缺或感染，先查血，不要在家扛。

立即

干咳、气短、呼吸困难——警惕免疫性肺炎、肺栓塞、大量胸腹水。

立即

腹围短期明显增大、憋气——大量腹水。

立即

意识模糊、嗜睡、胡言乱语——警惕肝性脑病（肝病患者尤其注意）。

立即

甲状腺全切术后：手麻口唇麻、肌肉抽搐——急性低钙。

立即

颈部/手术区迅速肿胀、憋气、呼吸困难——术后出血压迫气道。

立即

胸痛、心慌、晕厥——警惕心肌炎（免疫治疗相关）或心血管事件。

立即

外伤性摔倒后意识改变、或长期卧床者突发单侧肢体无力——警惕脑出血/脑梗。

去急诊时带：病历本、出院小结、正在服用的所有药物（或清单）、最近的检查报告。

5钱与资源

问得最多、最没人系统讲的部分。所有报销政策以当地医保局和医院为准。

医保、大病保险、惠民保、双通道
  • 基本医保：目录内药品分甲类（全报一部分）和乙类（先自付一部分再报销）；目录外（丙类）自费。
  • 大病保险：基本医保报完后，个人负担超过起付线的部分可「二次报销」，无需另外投保，自动结算。
  • 医疗救助：低保、特困等困难家庭可向民政/医保部门申请。
  • 惠民保：各地城市定制型商业补充医疗险（如沪惠保、穗岁康等），投保门槛低、保费便宜，对既往症常有一定保障——建议关注自己城市的版本。
  • 双通道：部分国谈药可凭医生处方在「双通道药店」购药并报销，问医院医保办怎么走流程。
  • 异地就医：跨省看病先办「异地就医备案」（国家医保服务平台 App 可办），报销比例和流程更顺。
用自费药前先问医生：进没进医保、报多少、有没有替代方案；医院有「医保办」窗口，具体问题直接去问。
慈善援助与患者援助项目
  • 正规的患者援助项目（赠药/费用减免）通常通过中华慈善总会、中国初级卫生保健基金会、白求恩公益基金会等机构执行，项目随药企政策变化，以项目方最新公告为准。
  • 获取方式：问主治医生或医院药房、药学门诊；基金会有官网和热线，注意核实真伪。
  • 大病众筹（水滴筹等）：慎用，注意隐私泄露和亲友负担；先走完医保、大病保险、医疗救助、惠民保再考虑。
防骗：正规援助项目不收取任何「代办费、手续费」。任何声称「帮你操作援助、先交钱」的都是诈骗。
随访时间表（肝胆胰、十二指肠术后）
  • 一般术后 2 年内每 3 个月复查（肿瘤标志物+影像），2-5 年每 6 个月，5 年后每年——以主管医生的书面计划为准。
  • 每次复查带齐：出院小结、病理报告、影像原片、既往化验单、用药清单（含剂量）。
随访时间表（甲状腺术后 / 结节）
  • 甲状腺癌术后：术后前 2 年每 6-12 个月查甲功+Tg+颈部超声，稳定后延长间隔。
  • 甲状腺良性结节：6-12 个月复查超声，连续稳定可延长至 1-2 年。
每次复查带齐：出院小结、病理报告、影像原片、既往化验单、用药清单（含剂量）。
随访时间表（胆囊结石）
  • 未手术的胆囊结石：每年一次超声+症状评估。
  • 胆囊切除术后一般无需长期随访，按医嘱复查肝功能即可。
随访时间表（胆总管结石）
  • 胆总管结石取石后按医嘱复查（超声/MRCP），一般 6-12 个月一次。
  • 出现腹痛、发热、黄疸随时就诊，不要等复查时间。

6就医实用贴士

看门诊 / 复查前准备什么（清单模板）
  • 带齐资料：病理报告、出院小结、影像原片（光盘/二维码）、历次化验单、用药清单。
  • 把想问的问题提前写在手机备忘录里，逐条问，别当场忘。
  • 对诊断有疑虑可申请病理会诊 / 影像会诊（挂大医院的「会诊号」，带切片/原片）。
  • 复杂肿瘤主动问：「我的情况需要多学科会诊（MDT）吗？」——外科、内科、放疗、病理一起讨论往往更稳妥。
见医生必问清单（万能模板）
  • 我/家人的诊断和分期是什么？治疗目标是什么（根治/控制/延长）？
  • 这个方案为什么适合？有没有替代方案？各自的利弊？
  • 副作用有哪些？出现什么情况需要联系您/去急诊？
  • 下一步什么时候复查？查什么？
  • 有没有临床研究或慈善援助的机会？
  • 回家后饮食、活动、服药有什么特别注意？
